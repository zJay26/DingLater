# DingLater v2.7.1

本次补丁更新了 Windows 便携版的运行时依赖和随包许可文件。

- Windows App SDK 升级至 2.4.0，随包 WinUI 版本为 2.3.6。
- 项目采用 MIT 许可证。便携包根目录新增 `LICENSE` 和 `THIRD-PARTY-NOTICES.md`，第三方许可及版权声明随包提供，并纳入文件完整性校验。
- README 补充了使用范围与责任说明。仅限本人账号与本人设备，公司账号请先确认组织政策。

## 下载与更新

下载 `DingLater-2.7.1-win-x64-portable.zip` 和 `SHA256SUMS.txt`。核对 SHA-256 后完整解压，双击 `DingLater.exe` 运行。v2.4.0 及以上版本也可在“设置 → 软件更新”中升级。
