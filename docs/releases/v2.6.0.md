# DingLater v2.6.0

新增 Windows 原生风格的托盘悬停列表，按人汇总待处理消息，并支持一键标记全部已处理。

## 托盘待处理列表

- 悬停托盘图标后向上显示浮层，列出每个人的待处理数量、最近一条待处理消息和时间；已处理与稍后提醒消息不会混入预览。
- 同一发送者在不同会话中的待处理消息归并显示，按最近待处理时间排序。列表可滚动，底部操作保持固定。
- 鼠标从图标移入浮层时保持列表打开；离开后延迟关闭。浮层显示不主动激活窗口，点击联系人只打开 DingLater 中保存的消息。
- 右下角“全部已处理”直接标记整个待处理分类，不受主窗口当前页面或搜索条件影响。稍后提醒和消息正文保留，操作仅改变 DingLater 的本地状态。
- 关闭消息预览时隐藏联系人和正文。空列表显示捕获状态，批量处理期间按钮不可重复触发。
- 使用系统支持的 Acrylic 材质与圆角，不支持时采用实色背景；保留系统主题与无障碍控件。

## 下载与更新

- 发布 Windows x64 自包含便携 ZIP 和 `SHA256SUMS.txt`，无需另装 .NET 或 Windows App Runtime。
- v2.4.0 及以上用户可在“设置 → 软件更新”检查、下载并确认重启更新。也可退出旧版，将 ZIP 完整解压到新目录后运行。
- 保留原有本地消息、设置、捕获规则、提醒及窗口置顶功能，不修改钉钉的消息或已读状态。

## 验证范围

- Windows/Core Release 回归：108 项通过，1 项真实钉钉数据库探针按默认规则跳过。
- 新增回归覆盖按人归并、最新待处理消息、隐私关闭、未知发送者、emoji，以及 DPI、多显示器和顶部任务栏的布局边界计算。
- 隔离的实际 WinUI 窗口验证 5 位联系人、12 条待处理消息全部转为已处理，并保留原有稍后消息；主窗口处于其他分类且有搜索条件时结果一致。
- 正式包执行锁文件恢复、格式检查、合成浮层验收、完整解压与逐文件校验、真实 WinUI 启动及隔离更新交接验证。
- WinUI 布局截图使用实色背景；真实桌面的鼠标悬停过渡、滚动及 Acrylic 外观仍需实际设备验收。真实双账号已读回执与其他兼容性边界见[兼容性与验收](https://github.com/zJay26/DingLater/blob/v2.6.0/docs/COMPATIBILITY.md)。
