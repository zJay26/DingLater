# DingLater v2.1.0

本版本重点优化 Windows 图标和桌面托盘提醒体验。

## 更新内容

- 将应用与托盘图标恢复为紫色时钟方案，并提高小尺寸图标的画布占用率和辨识度。
- 待处理消息在托盘图标右上角显示数量角标，超过 99 条显示 `99+`。
- 有待处理消息时，托盘图标以更亮的紫色闪烁；遵循 Windows 的动画开关。
- 悬停托盘图标时显示最新待处理消息摘要，可沿用通知预览隐私设置隐藏正文。
- 修复右键托盘菜单中“打开 DingLater”“暂停捕获”和“退出 DingLater”不执行的问题。
- 为托盘数量、摘要文本和菜单命令路由增加回归测试。

## 下载与校验

下载 `DingLater-2.1.0-win-x64-portable.zip` 并完整解压，然后双击 `DingLater.exe`。请不要只复制 EXE；程序需要同目录中的 Windows App Runtime 和资源文件。

可使用同一 Release 中的 `SHA256SUMS.txt` 校验 ZIP。程序仍未进行代码签名，因此 Windows 可能显示 SmartScreen 提示。

兼容范围与隐私边界见仓库中的 `docs/COMPATIBILITY.md` 和 `docs/PRIVACY.md`。
