# DingLater v2.2.0

本版本集中改进 Windows 版的消息捕获效率、异常恢复和本地数据安全。此 Release 仅提供 Windows x64 便携包。

## 更新内容

- 只有检测到钉钉 V3 消息分表确实前进时才创建只读快照，并只查询进度发生变化的分表，减少空轮询和重复扫描。
- 加强捕获启动、停止和退出时的清理逻辑；部分来源启动失败时会回滚已启动来源，单个来源停止失败也不会阻断其余清理。
- 修复删除、批量处理、缩短留存期等操作中的提醒清理边界，降低残留提醒再次弹出的可能性。
- 加强本地主密钥和消息加密对象的生命周期管理；更新 SQLite 运行库并补充密文篡改、释放后误用等测试。
- 改进首次设置、留存期修改和重复启动时的错误恢复与提示，保存失败时会恢复界面状态。
- Windows portable 构建脚本支持显式选择项目固定的 .NET SDK 路径。

## 验证

- Release 测试：64 项通过，1 项需要真实钉钉 V3 数据的测试按设计跳过，0 项失败。
- Windows x64 自包含便携包完成 locked restore、Release 测试、publish、WinUI 资源检查和窗口启动冒烟检查。
- ZIP 文件与 `SHA256SUMS.txt` 在上传前后分别核对。
- 本版本没有进行真实双账号的发送方未读状态验收，不把只读代码边界描述为端到端保证。

## 下载与校验

下载 `DingLater-2.2.0-win-x64-portable.zip` 并完整解压，然后双击 `DingLater.exe`。请不要只复制 EXE；程序需要同目录中的 Windows App Runtime 和资源文件。

可使用同一 Release 中的 `SHA256SUMS.txt` 校验 ZIP。程序仍未进行代码签名，因此 Windows 可能显示 SmartScreen 提示。
