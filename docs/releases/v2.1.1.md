# DingLater v2.1.1

本版本修正窗口关闭与托盘运行逻辑。

## 更新内容

- 点击主窗口右上角“×”时仅隐藏软件界面，DingLater 继续在桌面托盘运行并捕获、提醒消息。
- 双击托盘图标或选择“打开 DingLater”可以重新显示主界面。
- 只有右键托盘图标并选择“退出 DingLater”才会清理资源并真正结束进程。
- 增加窗口隐藏与托盘退出生命周期回归测试。

## 下载与校验

下载 `DingLater-2.1.1-win-x64-portable.zip` 并完整解压，然后双击 `DingLater.exe`。请不要只复制 EXE；程序需要同目录中的 Windows App Runtime 和资源文件。

可使用同一 Release 中的 `SHA256SUMS.txt` 校验 ZIP。程序仍未进行代码签名，因此 Windows 可能显示 SmartScreen 提示。
