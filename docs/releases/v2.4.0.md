# DingLater v2.4.0

Windows 版新增可选自动更新。更新检查、下载与重启分别由设置和用户选择控制，不强制升级。

## 软件更新

- 默认运行期间每 6 小时检查一次 GitHub 最新正式版本，可在“设置 → 软件更新”关闭。检查时间跨重启保留；离线或请求失败后按正常间隔重试，随时可以手动检查。
- 发现新版显示可关闭的应用内提示，可查看版本说明、下载或跳过此版本；手动检查可重新显示已跳过版本。
- 下载目录可通过系统文件夹选择器配置，默认 `%USERPROFILE%\Downloads\DingLater`。每次下载使用独立子目录，显示进度并支持取消。
- 下载后先校验 GitHub Release 的 SHA-256 摘要，再解压并逐文件校验，拒绝不完整、损坏、路径越界或重复路径的包。
- 下载完成后仍需点击并确认“重启并更新”。更新助手等原应用退出，备份旧版文件、应用新版并重新启动；文件替换失败时尝试回滚。下载、备份文件保留，便于恢复。
- 保留原程序目录、快捷方式、登录启动项，以及本地消息和设置。目录权限不足或文件被占用时显示错误，可重试或手动解压更新。

## 隐私与交付

- 仅更新客户端访问 GitHub 和其下载 CDN；不上传消息、钉钉账号、密钥或诊断，没有遥测与云同步。
- 自动检查只获取版本信息，不自动下载或重启，也不唤醒已退出的应用。
- 包含 Windows x64 便携 ZIP 与 `SHA256SUMS.txt`，无需安装 .NET 或 Windows App Runtime。
- 旧版本尚无更新入口，需要手动下载本次 ZIP，完整解压后运行；之后即可使用应用内更新。

## 验证

发布前执行 Windows/Core Release 回归、锁文件恢复与格式检查，验证 ZIP 完整解压、逐文件校验及真实 WinUI 窗口启动。另在两个隔离目录以模拟旧版清单验证更新助手握手、原进程退出、文件替换、旧版备份与新版重新启动。测试使用合成消息，不触碰正在运行的真实实例。

真实钉钉数据库探针默认跳过；双账号发送方“未读”、独立 Windows 用户隔离、实际断电恢复和不同机器上的权限/杀毒软件行为仍需环境验收。兼容性见 [COMPATIBILITY.md](../COMPATIBILITY.md)。
