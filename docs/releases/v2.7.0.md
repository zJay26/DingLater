# DingLater v2.7.0

全面改进 Windows 版界面：统一品牌配色，重新整理会话列表、消息详情与设置页，并加强读屏与键盘支持。消息捕获、存储和更新逻辑保持不变。

## 界面与交互

- 按钮、导航指示、数量徽标、开关和选中标记统一使用 DingLater 紫色，不再混用系统强调色；浅色、深色主题文字对比度满足 WCAG AA，High Contrast 继续使用系统颜色。
- 原先占据一整行的捕获状态改为导航栏右侧的状态标签，列表可显示更多内容；点开可查看捕获来源详情并暂停或恢复，暂停期间页面顶部持续提示。
- 会话列表增加头像（群聊显示群组图标）、消息条数、@我 与 DING 标签和下次提醒时间；时间显示为“16:41 / 昨天 / 周三 / 明天 09:00”，跨过午夜后自动更新。
- 消息详情显示会话类型与条数；操作栏按钮带图标，“已处理”固定在右侧；右键消息或按 `Ctrl + C` 可复制正文。
- 每个分类和搜索结果都有对应的空状态说明。
- 设置页改为 Windows 11 风格分组卡片；软件更新整合为一张卡片；“群聊收取范围”改为下拉选择；诊断信息复制后就地显示“已复制”。
- 首次使用引导、启动画面和托盘浮层与主界面使用同一套样式。

## 修复

- 窄窗口（单栏）下刷新、启动或方向键浏览不再意外跳入详情页；返回列表后可再次打开同一会话。
- 多个对话框不再可能同时弹出导致异常；对话框跟随界面字号。
- “特大”等字号下设置卡片的说明文字同步放大，搜索框提示不再被截断。
- 切换系统深浅色后，状态颜色同步更新。
- 修复切换字号时页面实例未释放、托盘图标在无待处理时反复重绘的问题。

## 无障碍与快捷键

- 列表项向读屏软件朗读会话名、条数、时间与摘要，不再读出程序类型名；页面标题提供标题层级，状态变化会播报。
- `Ctrl + 1/2/3` 切换待处理、稍后提醒、已处理，`Ctrl + F` 搜索，`Alt + ←` 返回会话列表。

## 下载与更新

- 发布 Windows x64 自包含便携 ZIP 和 `SHA256SUMS.txt`，无需另装 .NET 或 Windows App Runtime。
- v2.4.0 及以上用户可在“设置 → 软件更新”检查、下载并确认重启更新；更早版本请手动下载 ZIP，完整解压后运行。
- 保留原有本地消息、设置、捕获规则、提醒及窗口置顶功能，不修改钉钉的消息或已读状态。
