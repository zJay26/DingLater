# DingLater v2.5.0

新增系统范围的窗口置顶功能，复用 DingLater 常驻进程，不需要额外运行 PowerToys 或其他工具。

## 窗口置顶

- 按 `Ctrl + Win + T` 置顶当前应用窗口，再按一次取消；可同时置顶多个窗口，长按不会反复切换。
- 置顶窗口显示持续的系统高亮色描边，鼠标可穿透，不抢焦点、不播放音效。描边跟随移动、缩放、最小化、恢复及最大化，并在目标关闭或取消置顶后清理。
- 点击 DingLater 的“×”隐藏到托盘后，快捷键仍然有效，不依赖消息捕获是否暂停。
- 在“设置 → 窗口置顶”启用或关闭功能。关闭功能立即取消本次由 DingLater 设置的置顶；默认正常退出时也会取消，可选择退出后保留。
- 快捷键被其他程序占用或窗口权限不足时给出提示。若 PowerToys 已占用 `Ctrl + Win + T`，先释放它，再重新开启 DingLater 的置顶开关。

## 隐私与兼容性

- 使用 Windows 原生窗口 API 和进程外窗口事件，不增加常驻进程或定时扫描，不注入目标进程，不模拟输入，不读取或保存窗口标题、内容、截图。
- 消息捕获路径继续保持只读；置顶功能与钉钉数据库捕获分离。
- 普通权限运行时，部分管理员窗口无法操作；置顶不保证覆盖其他置顶窗口、独占全屏或自行管理层级的应用。强制结束进程或崩溃时，Windows 可能保留目标的置顶状态，可重启 DingLater 后按快捷键取消。

## 下载与更新

- 发布 Windows x64 自包含便携 ZIP 和 `SHA256SUMS.txt`，无需另装 .NET 或 Windows App Runtime。
- v2.4.0 用户可在“设置 → 软件更新”检查、下载并确认重启更新。更早版本请手动下载 ZIP，完整解压后运行。
- 保留原有本地消息与设置；仅新增窗口置顶及退出恢复选项。

## 验证

- Windows/Core Release 回归：99 项通过，1 项真实钉钉数据库探针按原有规则跳过。
- 新增 9 项测试，覆盖旧设置兼容、置顶切换、多窗口、描边空心区域与穿透样式、移动/缩放、最小化/恢复、窗口销毁、外部取消置顶、退出清理和快捷键冲突。
- 本机合成数据实例已现场验证描边、设置开关、隐藏到托盘后的跨进程置顶、最大化跟随和再次按键取消；现场自动化使用测试组合键，生产快捷键固定为 `Ctrl + Win + T`。
- 发布包执行锁文件恢复、格式检查、完整解压与逐文件校验、真实 WinUI 启动，以及隔离目录中的更新交接验证。
- 多显示器混合 DPI、虚拟桌面、管理员窗口及第三方特殊窗口未完成现场验收。详细范围见仓库的 `docs/COMPATIBILITY.md`。
