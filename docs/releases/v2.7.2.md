# DingLater v2.7.2

- Windows 版现在会捕获自己发出的 `@自己` 消息，并在“待处理”标为 `@我`。在自己的机器人私聊里，用钉钉的 `@` 选择器选中自己的账号，再发一条新消息即可自测。
- 已使用钉钉 Windows `9.0.10.261117008` 验证 V3 数据库、WAL 和增量捕获。

## 下载与更新

下载 `DingLater-2.7.2-win-x64-portable.zip` 和 `SHA256SUMS.txt`。核对 SHA-256 后完整解压，双击 `DingLater.exe` 运行。v2.4.0 及以上版本也可在“设置 → 软件更新”中升级。

[兼容性与验收范围](https://github.com/zJay26/DingLater/blob/v2.7.2/docs/COMPATIBILITY.md)
