# DingLater v2.1.2

本版本改进桌面托盘的待处理提示、批量消息操作与稍后提醒展示，并固定本地测试产物位置。

## 更新内容

- 待处理消息到达后，托盘图标会在完全透明与完全不透明之间闪烁；数量角标更清晰。
- 鼠标悬停托盘图标时显示待处理总数和截断后的最新消息摘要，避免长消息占满提示框。
- 单击托盘图标即可打开 DingLater，不再要求双击。
- “待处理”和“稍后提醒”增加“全部标为已处理”；批量处理稍后提醒时会同步取消对应的 Windows 提醒。
- “已处理”增加带确认提示的“全部删除”。
- 每条稍后提醒消息都以醒目标签显示完整提醒日期和时间。
- 本地最新测试版固定输出到 `BuildOutput\DingLater.exe`，仓库根目录提供 `启动最新版本.cmd`；构建临时目录在完成后自动清理。

## 验证

- Release 测试：59 项通过，1 项需要真实钉钉 V3 数据的测试按设计跳过。
- 自包含便携包与固定输出目录均完成窗口启动冒烟测试。

## 下载与校验

下载 `DingLater-2.1.2-win-x64-portable.zip` 并完整解压，然后双击 `DingLater.exe`。请不要只复制 EXE；程序需要同目录中的 Windows App Runtime 和资源文件。

可使用同一 Release 中的 `SHA256SUMS.txt` 校验 ZIP。程序仍未进行代码签名，因此 Windows 可能显示 SmartScreen 提示。
